# Budget Tracker App

A responsive budget tracking application built with **HTML**, **CSS**, and **JavaScript**.  
This app allows users to record income and expenses, calculate balances, and visualize spending habits.

---

## ✨ Features
- **Add Income & Expenses** — input transactions with description and amount.
- **Balance Calculation** — automatically updates total balance, income, and expenses.
- **Persistent Storage** — saves data using localStorage so your records remain after refresh.
- **Responsive Design** — works smoothly on desktop and mobile.
- **Clear UI** — simple layout for easy tracking.

---
